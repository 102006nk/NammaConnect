# NammaConnect — Your Everyday Kannada Assistant

## About the Project
NammaConnect is a simple, mobile-friendly Kannada-English web application designed to help people communicate in everyday situations in Karnataka. It provides useful Kannada phrases with English meanings for travel, shopping, college, restaurants, and hospitals.

## Problem Statement
People who are unfamiliar with Kannada may face communication difficulties while travelling, studying, shopping, or accessing everyday services in Karnataka.

## Our Solution
NammaConnect helps users learn and use common Kannada phrases through a simple interface. Users can search for phrases, browse categories, practise through a quiz, and use browser-supported speech features.

## Key Features
- Search for Kannada phrases and their English meanings
- Browse phrases by everyday categories
- Practise Kannada using a quiz
- Use text-to-speech where supported by the browser
- Responsive design for mobile and desktop screens
